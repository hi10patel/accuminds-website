PINT AE rules · UAE e-invoicing

PINT AE invoice type codes: 380, 480, 381 and 81

Which code each document uses, and linking credit notes to invoices.

Check your invoices free → E-invoicing readiness service

Plain-English summary of the published specification, checked against 19 October 2026 (PINT AE Billing 1.0.4). The specification itself is authoritative.

The short answer

Each document needs a type code (IBT-003, IBR-004). PINT AE uses 380 for a tax invoice, 480 for an invoice out of scope of tax, 381 for a credit note and 81 for a credit note related to goods or services. Credit notes (381 and 81) must reference the original invoice (IBT-025, IBR-055-AE) unless the credit note reason code is VD.

The checks

What we check, and how to fix it.

Each check below runs in our free e-invoice readiness checker. Critical checks count towards the readiness score; warnings are listed but carry no weight.

CriticalChecker rule AE-009

Invoice type code present (380 tax invoice, 480 out of scope of tax, 381 credit note, 81 credit note for goods or services)

Official references
PINT AE IBT-003 Invoice type code; IBR-004, IBR-CL-01; AE code lists: invoice 380, 480; credit note 381, 81
Applies to
All invoices
How to fix
Map each document to its PINT AE type code: 380 tax invoice, 480 invoice out of scope of tax, 381 credit note, 81 credit note related to goods or services.
CriticalChecker rule AE-010

Credit note references the original invoice number

Official references
PINT AE IBG-03 / IBT-025 Preceding invoice reference; IBR-055-AE (required for 381 and 81 unless the credit note reason code is VD)
Applies to
Credit notes (type codes 381 and 81)
How to fix
Link every credit note to the original tax invoice number in the ERP before posting.
Note
The VD reason-code exception is not modelled because ERP exports rarely carry the reason code.

Questions

Common questions, answered.

What is invoice type code 480 in the UAE?

An invoice out of scope of tax. A tax invoice uses 380.

Does a UAE e-credit note need the original invoice number?

Yes, for type codes 381 and 81, unless the credit note reason code is VD (IBR-055-AE).
