Invoice line rules in PINT AE

Item names, quantities, prices, line totals and line VAT.

Check your invoices free → E-invoicing readiness service

Plain-English summary of the published specification, checked against 19 October 2026 (PINT AE Billing 1.0.4). The specification itself is authoritative.

The short answer

Each line needs an item name (IBT-153, IBR-025) and description (IBT-154, IBR-125-AE), a quantity (IBT-129, IBR-022), a net price (IBT-146) and a line net amount (IBT-131, IBR-024). The line net amount must equal quantity times net price (per base quantity), plus line charges, minus line allowances (IBR-147-AE). Each line also carries its VAT amount (BTAE-08), which is zero on reverse charge and zero-rated lines (IBR-162-AE, IBR-165-AE).

The checks

What we check, and how to fix it.

Each check below runs in our free e-invoice readiness checker. Critical checks count towards the readiness score; warnings are listed but carry no weight.

CriticalChecker rule AE-013

Line item description present

Official references
PINT AE IBT-153 Item name (IBR-025); IBT-154 Item description (IBR-125-AE)
Applies to
All invoices
How to fix
Every invoice line needs an item name or description of the goods or services supplied.
Note
PINT AE carries both an item name and an item description; one description column is checked here.
CriticalChecker rule AE-014

Line quantity present and numeric

Official references
PINT AE IBT-129 Invoiced quantity; IBR-022
Applies to
All invoices
How to fix
Export quantity as a number on every line (service lines usually use 1).
CriticalChecker rule AE-015

Line unit price present and numeric

Official references
PINT AE IBT-146 Item net price; IBR-026, IBR-027
Applies to
All invoices
How to fix
Export the net unit price (excluding VAT) as a number on every line.
CriticalChecker rule AE-016

Line net amount present and numeric

Official references
PINT AE IBT-131 Invoice line net amount; IBR-024
Applies to
All invoices
How to fix
Export the line amount excluding VAT as a number on every line.
CriticalChecker rule AE-019

Line net amount = quantity x unit price (less line discount), tolerance 0.01

Official references
PINT AE IBR-147-AE: line net amount = quantity x (net price / base quantity) + line charges - line allowances
Applies to
All invoices
How to fix
Recalculate line net = quantity x unit price - line discount, rounded to 2 decimals. Check for prices stored with VAT included.
Note
Assumes a price base quantity of 1 and treats line discounts as allowances.
CriticalChecker rule AE-020

Line VAT amount = line net x VAT rate (zero on reverse charge and additional VAT lines), tolerance 0.01

Official references
PINT AE BTAE-08 VAT line amount (IBR-104-AE, IBR-123-AE); IBR-162-AE (zero on reverse charge lines), IBR-165-AE (zero on zero rated lines), IBR-108-AE (additional VAT tax amount is zero)
Applies to
All invoices
How to fix
Export the VAT amount per line and make sure it equals line net x rate, rounded to 2 decimals.
Note
For non-AED invoices PINT AE needs the line VAT in AED as well; this check compares amounts in the invoice currency.

Questions

Common questions, answered.

Is a short item code enough as the line description?

No. PINT AE carries an item name (IBR-025) and an item description (IBR-125-AE), so each line needs a readable description of the goods or services.

Why does the line net amount not match quantity times price?

Usually because prices are stored with VAT included, a line discount is missing, or the amount is not rounded to 2 decimals (IBR-147-AE).
